# 摸鱼鸭 · 欸~你听说没~（合并版）

[<img src="icon.png" width="96" align="right" alt="摸鱼鸭">](#)

把「摸鱼鸭」桌面宠物和「欸~你听说没~」局域网点对点聊天**合成了一个软件**：
一个进程、一个托盘图标、一套配置。

**收到消息时，桌面顶层会钻出一条小鱼（气泡里就是那条消息），小鸭子会从屏幕外跑过来把它吃掉。**

面向统信 UOS / deepin / 银河麒麟等国产 Linux 桌面，免注册、免服务器，知道对方 IP 就能聊。

---

## 效果

```
收到消息
  └─> 屏幕最上层钻出一条小鱼，头顶气泡里是消息内容
        └─> 小鸭子从屏幕外面一路小跑进来（桌面那层的鸭子同时"消失"）
              └─> 一口把鱼吃掉，撒一圈星星，说「嘎！消息我吃掉了~」
                    └─> 跑出屏幕，回到桌面继续溜达
```

- 动画在一个**透明 + 置顶 + 鼠标穿透**的窗口上播放，不挡点击、不抢焦点
- 群消息也会触发，自己发的不会；消息连着来会排队（最多 3 条）
- 点一下桌面上的小鱼，它告诉你**离下班还有多久**，下班时间可在菜单里自定义

想先看效果：`bash 启动.sh --demo`

## 快速开始

```bash
cd 摸鱼鸭聊天版
bash 启动.sh                 # 缺 PyQt5 会提示怎么装
bash 安装到应用菜单.sh        # 可选：放一个「摸鱼鸭·聊天」进应用列表
```

两台机器连起来：

1. 两边都运行程序（自动开始监听，界面显示「● 监听中 50010」）
2. 任一方填对方 IP + 端口 → 点「连接」
3. 懒得问 IP：点「扫描局域网」自动发现

依赖：`python3` + `PyQt5`。

## 功能

| | |
|---|---|
| 单聊 | 文字消息 + 任意文件（64KB 分块、带进度） |
| 群聊 | 建群 / 加人 / 退群，msg_id 去重 + 两跳转发 |
| 发现 | UDP 广播自动找人，广播不通自动改成网段逐个握手 |
| 传文件 | 弹窗确认保存位置，实时进度 |
| 宠物 | 溜达、钻鱼、吃鱼、拉屎，可拖动、可调大小速度、可暂停 |
| 联动 | 收到消息 → 顶层弹鱼 → 鸭子跑去吃 |
| 下班倒计时 | 点小鱼查看，下班/上班时间可在菜单里改（精确到分钟） |
| 托盘 | 一个图标管所有：窗口、宠物、联动开关、下班时间、退出 |

完整用法、排障见 **[使用说明.md](使用说明.md)**。

## 常用参数

```bash
--demo              启动后自动演示一次吃鱼动画
--no-pet            不要桌面鸭子，只聊天
--no-link           收到消息时不放鱼
--p2p-port 50011    换聊天端口（50010 被占用时）
--off-hour 17 --off-minute 30
--size big          鸭子大小（small / normal / big）
--selftest          网络层自检   --diag 环境诊断
--report            导出诊断报告（环境/网卡/端口/日志）到文本文件
```

## 出问题怎么排查

程序一直在记运行日志（`~/.moyuya_chat.log`，超过 512KB 自动滚动），
任何没被接住的异常（含子线程）都会连堆栈一起记下来。

导出一份报告发给开发即可，**不含聊天内容**：

```bash
python3 摸鱼鸭聊天版.py --report
# 或：窗口菜单 帮助 → 导出诊断报告…
# 或：托盘右键 → 导出诊断报告…（窗口打不开时用）
```

报告包含：系统/Python/Qt 版本、识别到的网卡（IP/掩码/广播地址/识别方式）、
端口占用情况、当前监听与连接状态、最近的运行日志。

## 目录结构

```
摸鱼鸭聊天版/
├─ 摸鱼鸭聊天版.py      主程序（单文件）
├─ 启动.sh              一键启动（自动检查 PyQt5）
├─ 安装到应用菜单.sh     放到系统启动器
├─ 使用说明.md
├─ icon.png
└─ tools/              构建脚本（主程序由这些脚本拼出来）
```

> ⚠️ `摸鱼鸭聊天版.py` 是**自动生成**的：聊天内核 + 宠物绘制 + 界面三部分拼成。
> 改功能请改 `tools/_part3.py`，再跑 `python3 tools/build.py` 重新生成，
> 直接改生成出来的大文件会在下次构建时被覆盖。

## 安全提示

- 消息与文件**明文传输**、不做身份校验，只适合办公室 / 内网可信环境
- 跨公网请先打通 VPN / WireGuard / SSH 隧道，不要把端口直接暴露到互联网
- 群成员关系只存内存，程序一关群就没了（没有服务器帮大家记）
- 本程序不连接任何外部服务器；UOS 安全中心弹「是否允许联网」时选允许并加白名单

## 协议兼容

协议层（TCP/UDP + JSON 帧）与旧版「欸~你听说没~」完全一致，
**和同事电脑上没升级的旧版可以互相加好友、聊天、传文件**。
